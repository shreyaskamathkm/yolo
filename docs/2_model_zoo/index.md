# Model Zoo

The YOLO Model Zoo provides a collection of pre-trained models and architectural configurations for various computer vision tasks.

## Overview

We support multiple YOLO versions and variants, optimized for different hardware and performance requirements.

### Supported Tasks
- **Object Detection**: Real-time detection of multiple objects with bounding boxes.
- **Instance Segmentation**: Precise pixel-level masking of objects (Coming soon).
- **Keypoint Detection**: Human pose estimation and facial landmarking (Planned).
